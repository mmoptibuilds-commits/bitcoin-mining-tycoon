# frontend-design

Read DESIGN_SYSTEM, UX_SPEC, APP_IDENTITY, FEATURES and the UI rule. Design hierarchy around the player's facility and next action before styling. Preserve graphite/copper; ordinary readable copy; numeric telemetry secondary. Use existing theme/components with coherent tokens and original bounded Canvas/vector motifs. Cover new/migrated/early/late/locked/deficit/large-value states, system splash/launcher and accessible settings/feedback. Inspect all scene stages and actual actions on emulator; 48dp, font1.5, TalkBack, reduced motion, insets/back. Never use web/React/CSS instructions, generated imagery, template Android robot or generic dashboard patterns.
